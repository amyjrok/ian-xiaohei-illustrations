## 第一轮：分析两个视频

**用户请求**：根据上传的两个视频，分析用什么搭建的网站、具体步骤，以及如何搭建"中考英语1500词"网站，包括操作步骤、难点、门槛。

**我的分析结论**：

两个视频都是**成品演示**（小红书博主"林小词Lin"的作品），没有出现搭建界面。可确认的产品特征：

| 维度 | 特征 |
|---|---|
| 载体 | 浏览器里的 H5 网页（iPad Safari 打开），非原生 App |
| 布局 | 单页：首页/我的 + 章节正文 + 目录/词卡 |
| 模式 | 学习版 / 隐藏中文 / 隐藏英文 |
| 阅读器 | 章节导航、字号调节、挖空、逐词显示答案 |
| 批改 | 答案、清空、已答/正确统计 |
| 词卡 | 本课词卡、掌握/没记住、发音 |
| 数据 | 多本书、多章节，无登录无后端 |

**推断技术栈**：纯前端单页应用 + 静态 JSON 数据 + 静态托管，进度存 localStorage。**不太可能是纯扣子做的**（扣子没有阅读器组件，做不出逐词交互），扣子最多做内容工厂和 AI 能力。

**复刻流程（6步）**：切章 → 抽词标注（LLM批量+人工校对）→ 结构化JSON → 写渲染器 → 状态与进度 → 部署多端适配。

**中考1500词实现建议**：
- 路线A（推荐）：Trae生成单页HTML + 静态托管
- 路线B（扣子）：扣子做内容生产+AI能力，前端自建
- 难点：内容质检、合规、词形还原、练习设计、抗遗忘算法、部署备案

## 第二轮：确定产品形态

**用户**：只做本地网页，不上架小程序。把1500词融入漫画/小说/初中生感兴趣的故事，配合练习和抗遗忘。

**我的判断**：方向对，且视频里就是中文叙事里原位嵌入英文目标词。但需改三点：

1. **不要把1500词塞进一本故事** → 分30章×50词，主线贯穿
2. **抗遗忘不靠多练，靠调度** → 间隔重复(1/3/7/15/30天)+提取练习+交错复习
3. **漫画先降级成插图** → AI分镜一致性差，先文字+每章一张氛围图

**产品形态**：书架 → 阅读(三模式) → 练习(挖空/四选一/听音/拼写/搭配) → 复习(跨章节混合) → 错词本 → 我的(导出导入)

**数据结构**：`words`(词表) + `chapters`(分段token，词位标注)

**内容生产流水线**：词表整理 → 按场景分章 → LLM生成故事(每章30词) → 程序标注词位(词形还原) → 人工抽检(义项匹配) → 回填复现设计

**本地落地**：HTML+JS+localStorage，数据写为.js（避免file://下fetch失败），用`python -m http.server`给iPad访问

## 第三轮：生成第一章原型

**用户**：孩子喜欢校园悬疑，生成第一章示例。

**交付物**：`/workspace/vocab-story/` 本地网页原型 + `词汇故事-第01章原型.zip`

**第一章《午夜广播》**：寄宿部凌晨广播点名失踪学生陈屿，主角林一舟上天台调查，撞见学生会主席周凛和广播站长许棠争吵，发现第三盏灯，结尾陈屿现身、直播间标题"下一个，林一舟"。

- 正文约1000字，嵌入30个中考词（39词次，密度约3%）
- 30词：anxious, strange, whisper, disappear, discover, glance, pretend, argue, hurry, follow, shadow, silence, fear, approach, hide, cautious, abandon, warn, promise, curious, escape, honest, recognize, remind, notice, suspect, evidence, trust, brave, confess

**实现功能**：
- 三模式阅读：学习版/隐藏中文/隐藏英文
- 挖空默写（回车判定，正确变绿/错误抖动）
- 逐词眼睛显示释义
- 点词发音（浏览器TTS英式）
- 字号调节、已答/正确统计
- 词卡面板（音标、词性、释义、掌握/没记住）
- 抗遗忘：1/3/7/15/30/60天间隔，答错重置
- 复习页（今日到期，跨章节混合）
- 本地存储 + JSON导出/导入备份

**已修复问题**：桌面顶栏吸顶、IPA音标缺字（内置25KB字体）、掌握后统计不更新。

**运行方式**：解压后双击 index.html；iPad 用 `python3 -m http.server 8000` + 局域网IP访问。

**关键提醒**：30词是示例，需英语老师校对义项；按"每章30词×50章"扩到1500词，核心工作量在义项校对和词复现设计。
